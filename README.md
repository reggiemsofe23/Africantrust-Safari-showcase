# Africantrust Safari

A tourism website presenting Tanzania safari packages,
destinations, and travel experiences.

🌐 **Live website:** https://www.africantrustsafari.com/

## Overview

Africantrust Safari gives prospective travelers a place
to explore safari packages and learn about Tanzania's
tourism destinations.

## My Contribution

- Website development and page implementation.
- Organization of safari package and destination content.
- Presentation of travel information across the website.

## Technologies Used

| Technology | Purpose |
|------------|---------|
| PHP | Server-side functionality |
| HTML | Page structure |
| CSS | Styling and layout |
| JavaScript | Client-side interactivity |
| JSON | Structured data storage and exchange |
